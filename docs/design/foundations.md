## 3. 文字

- 書体は役割で 3 つに分ける。どれも Google Fonts から読み（`templates/app/index.html` の `<link>`）、読めないときは端末の書体で描く（`--font` はヒラギノ角ゴ → Noto Sans JP → Yu Gothic UI → Meiryo）。

| トークン | 書体 | 用途 | 書き方 |
|---|---|---|---|
| `--font` | M PLUS 1p | 日本語・英語の本文、見出し、ボタン、フォーム | 既定。何も書かない |
| `--font-num` | Inter | KPI、金額、統計値、ダッシュボードの数字 | `.num`（桁のそろう数字も付く） |
| `--font-code` | JetBrains Mono | ソースコード、JSON、SQL、ログ、CLI の表示 | `Code`・`CodeBlock` |

- 混ざるときは字ごとに決まる。`--font-num`・`--font-code` に無い字（かな・漢字）は `--font` の字になるので、`.num` の中に「1,234円」と書いてよく、書体を分けるために要素を分けない。文章の中の数字は本文の一部なので `.num` にしない。
- M PLUS 1p の太さは 100 / 300 / 400 / 500 / 700 / 800 / 900 だけで、Ignite が使う 600 は 700 の字で描かれる（Inter には 600 がある）。太さの決まりは変えない。
- コードの中の全角の字は `CodeBlock` が半角 2 桁の幅にそろえる（字は大きくせず字間を足すので、和文は少し広く見える）。半角カナと絵文字はそろわない。リガチャは使わない（`=>` を書いたとおりに見せる）。
- 書体をアプリのテーマで変えるときも `--font` だけを上書きする。`font-family` を部品の CSS に直接書かない（`ignite check` の注意）。
- 大きさは次の目盛りだけを使う。

| px | 用途 |
|---|---|
| 11 | ごく小さいラベル（タグ、グラフの目盛り） |
| 12 | 補足・件数・リンク・表の見出し・絞り込みタグ |
| 13 | 部品の本文（ボタン、一覧の行の名前、詳細の項目） |
| 14 | 画面の本文の基準・セクション見出し・グラフの見出し |
| 16 | 固定ヘッダーの名前・大きな見出しの名前・アイコンの頭文字（中）・タッチの端末の入力欄 |
| 20 | パネルの見出し・KPI の数字 |
| 24 | 画面のタイトル・ダッシュボードのタイルの数字（`Stat` の md） |
| 32 | ダッシュボードの主役の数字（`Stat` の lg。1 画面に 1〜2 か所だけ） |

- CSS では目盛りのトークン `var(--fs-12)` などで書き、px を直書きしない（`ignite check`）。トークンは `--text-scale` を掛けた値で、設定の「文字の大きさ」（12 章）が文字だけを大きくする。
- 例外：いちばん小さい顔アイコン（20px）の頭文字は 10px。顔アイコンの頭文字は丸の大きさに合わせるので px で書き、文字の大きさの設定でも変えない。
- **タッチの端末では、入力欄の文字を 16px にする**（`@media (pointer:coarse)`。iOS は 16px 未満の入力欄にフォーカスすると画面を拡大してしまい、戻すまで操作しづらい）。① の `.field` が持つので、入力欄は `.field`（`SearchField` など）で作る。ページの拡大を止める `maximum-scale=1` は、ピンチでの拡大も止めるので使わない。入力欄の案内文（placeholder）は、16px でもスマホ幅（320px）に収まる長さにする（対象 3 つまで）。監査がタッチの端末として開いて測る。
- 太さは 400（本文）/ 600（見出しの補助）/ 700（名前・見出し）。
- 1 行に収まらない名前は省略記号（`text-overflow: ellipsis`）。

## 4. 形

- **角丸**：`6`（小さな印・キー表示）/ `8`（小さい部品：アイコンの箱、一覧の行、切り替えの中のボタン、ツールチップ）/ `10`（ボタン・入力欄・ポップオーバー・切り替えの枠）/ `12`（カード・グラフ）/ `14`（パネル・ボード・引き出し）/ `99` または `50%`（丸い部品：タグ、顔アイコン、棒グラフの棒）。検索語のハイライト（`mark`）だけ 3。角丸の枠（ボード・パネルなど）の中で地を持つ段は、枠の角を塗らない（上の段は上の角、下の段は下の角に枠と同じ角丸を付けるか、枠で切る）。
- **影**：`--shadow-1`（切り替え・タブの選択中のボタン）/ `--shadow`（常に浮いているもの：ボード、パネル、カード、固定ヘッダー）/ `--shadow-hover`（詳細を開くカードのホバー）/ `--shadow-2`（ポップオーバー・引き出し・ボタン類のホバー）。
- **枠**：1px が基本。強調したいカード（選択中など）は 1.5px。チェック・ラジオの枠も 1.5px で色は `--ink-3`（選べる部品そのものなので、区切り線の扱いにせず地との比 3 を保つ）。
- **重なり**：`z-index` は `--z-scrim` < `--z-drawer` < `--z-popover` < `--z-toast` < `--z-tip` < `--z-skip` の順。画面全体の重なりはこのトークンを使うのが望ましい（検査はしない）。`Dialog` はブラウザの最前面に出るのでこの順の外にある。

## 6. 動き

| 長さ | 用途 |
|---|---|
| 0.12〜0.16s | ホバー、ツールチップ、小さな切り替え |
| 0.18〜0.22s | 開閉、出し入れ（パネル、固定ヘッダー、ポップオーバー） |
| 0.3〜0.35s | 表示位置の移動・拡大縮小、パネル枠の出し入れ（選んだものへ表示位置を運ぶ移動は、遠いほど長く 0.65s まで。遠くまで 0.35s で動くと目で追えない） |
| 0.6s | 数字・棒の長さの変化（`RollingNumber`・`Delta`・`BarList`・`ColumnChart`） |

- 長さのトークン: `--dur-fast`（0.14s）/ `--dur-base`（0.2s）/ `--dur-slow`（0.32s）。部品の CSS で使える（検査はしない）。
- 入り：`--ease-in-out`。スイッチの切り替え・数字や棒の変化だけは少し行き過ぎて戻る `--ease-spring`。出：`ease-in` で入りより短く。不透明度だけのフェードは `ease-out`。
- 例外：読み込み中の光（`Skeleton`、1.4s の繰り返し）、ツールチップは 0.25s 待ってから出す。
- 画面の途中に要素が差し込まれて下が押し下げられるときは `Collapse` で包む。読み込み中 → 中身は `Skeleton` → `Appear`。開閉は `Expandable`。画面側で独自のアニメーションを書かず、部品を使う。
- 閉じるものは「縮めるアニメーションを見せてから閉じる」。
- 文字の入れ替えは、数字は `RollingNumber`、語は `RollingWord`。待ちの文は `WaveText`（1.6s の繰り返し。`Skeleton` と同じく例外）。
