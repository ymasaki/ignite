## 7. 部品（画面の型）

### 画面の型

| 型 | 部品 | 中身 |
|---|---|---|
| アプリの枠 | `AppShell` | 左メニュー（`Brand`・`SideNav`・一番下の欄）、ヘッダー（画面の名前の `h1` と右の操作）、帯、内容の段、詳細パネル。画面の側で骨組みの大きさへの対応（`matchMedia`・左メニューやパネルの出し分け）を書かない |
| 一覧の画面 | `ListScreen` | 上に絞り込みの帯（`SearchField`・`Select`・`Segmented`、右端に件数）、普段と違う状態のときだけ `Notice`、残りは `EntityRow` の一覧（空なら `EmptyState`）。画面の見出し・説明文は置かない |
| ダッシュボード | `.kpis`（または `KpiBand`）＋ `Kpi`、`.chart-grid` ＋ `ChartCard` | 上に KPI の帯、その下に `ChartCard` の格子（`.chart-grid`。1 枚 360px 以上で折り返す。枠が 360px より狭いときは枠の幅）。グラフは `BarList`・`LineChart` の 1 色。指標の定義は `ChartCard` の `meta` に短く書く。グラフの選び方は下の表 |
| 設定 | `SettingsScreen` ＋ `SettingGroup` ＋ `SettingRow`（`Settings.tsx` / `settings.css`） | 左メニューの下の `SettingsButton`（「設定」）で、内容の領域を切り替えて出す（`AppShell` の `side` の中で `SideNav` の直後に置き、`collapsed` と閉じる操作を渡す。`foot` は文字の欄なので入れない。線が重なり、畳むと消える。`ignite check` が注意する）（ヘッダーは画面名だけ。メニューの項目を選ぶと戻る）。ほかの画面と同じ 1 枚の面（`.board`）の中に、まとまり（見出し 16px・下に主要色の薄い線、その下に行。まとまりの間は 36px）を縦 1 列に並べ、面の中でスクロールする（まとまりをばらばらのカードにしない。スクロールでヘッダーの下がぶつ切れになるため）。行は 720px で止め、面もその幅（768px）で止めて左に寄せる（広い窓で空の面を広げない）。中は「左に名前、右に選ぶ部品・値」の `SettingRow`（`onClick` を渡すと行ごと押せて、詳細パネルを開く）、自由な中身は `SettingBody`、キーは `SettingKey`。選んだらその場で効かせ、保存のボタンを置かない（例外: 見る人全員に効くなど書き終えてから当てたい設定は、入口の行から別の設定の画面に分け、`SettingsScreen` の `footer`（面の下端に固定する段）に「保存」「元に戻す」を置く。変えたときだけ押せる。ほかの設定の画面に保存のボタンを混ぜない）。テーマカラーの見本（`.swatch`）は、選んでも文字の太さを変えない（幅が変わらないように）。`SettingBody` の `note` は、送る前に知っておくべきことを 1 つだけ短く添える例外（9 章の「説明文を書かない」の例外。例: 名前つきで届くこと）。どのアプリにも `ThemeSettings`（テーマカラー・表示モード）を置く |
| バージョン履歴 | `ReleasePanel`（`Releases.tsx`。形と日付ごとのまとめ方は `releases.ts`） | 設定の「このアプリについて → バージョン」の行から右の詳細パネルに開く。同じ日の版を 1 つのまとまり（見出しは日付と版の範囲）にし、その中を機能追加・改善・不具合修正の順に分ける。履歴の中身はアプリが持つ |
| ログイン | `AuthScreen` ＋ `LoginForm` | `AppShell` の外に置く。窓の中央に幅 400px までの 1 枚の面（角丸 14・`--shadow`）を置き、上からアプリの印（48px）と名前（24px）を横に並べて中央に置き、入力の順に並べる。「ログイン」のような画面名の文言は目に見える形では置かない（印と名前で画面の目的が伝わる）が、読み上げ用の `h1` は `sr-only` で残す（カタログのように `AppShell` の中に見本として置いたときは、枠の `main` と `h1` を重ねないよう `div` と `h2` で描く）。入口の画面で主役はサービスなので、印と名前を 24px で置く（3 章の「画面のタイトル 24px」と同じ大きさ）。主ボタン（幅いっぱい）だけを主要色で塗り、飾りの絵や説明文を置かない。面の内側は 24px（画面にこの面しかないので、ほかの面より広くとる）。入力欄とボタンの高さは標準のまま（36px・34px）で、両方とも必須なので「必須」の印は出さない。外部の認証（Google・Apple・Okta など。`alternatives`）は「または」の線の下に、単色のロゴと「〇〇でログインする」の通常のボタンを縦に並べ、主ボタンを増やさない。再設定のリンクは入力欄の後に置く（Tab の順が欄の間に割り込まない）。窓が低いときは画面の中をスクロールする。入力の誤りは欄の下、認証の失敗は面の上の `Notice` に出し、どちらの欄が違うかを書かない（「メールアドレスかパスワードが違います」）。失敗したらメールアドレスを残し、パスワードの欄へ移る。2 段階認証は、パスワードが通ったあと同じ面の中身を `TwoFactorForm` に差し替える（画面を移らない・印と名前はそのまま）。欄は確認コードの 1 つだけなので、違うときは面の上でなく欄の下に「コードが違います」を出して升を揺らし、コードを空にして欄へ戻る。升は引き伸ばさず（幅 44px まで）、左右の端を主ボタンとそろえ、余った幅は升の間に等しく配る（3 桁ずつの間は升の間の 2 倍）。届き先は欄の補足に書き、主ボタンは「確かめる」。送り直しと戻るは欄と主ボタンの間に並べる |
| 詳細パネル | `PanelFrame` ＋ `PanelHeader` ＋ `PanelBody`（`Panel.tsx` / `panel.css`）＋ `Section` | 見出し（右上に×（`onClose` を省くと出さない。閉じない常時表示の詳細は `AppShell` の `panel.pinned` と組み、×を出さない）と、省略できる `actions`（任意のボタンの枠。文字のあるボタンを置くと上段は見出しの上の行になる）、大きなアイコン、補足、名前、行。名前が隠れたら固定ヘッダー `.pstick` が残り、`actions` と×もそこから押せる。固定ヘッダーの名前は省略せず、入らなければ 2 行にする。アイコンのある文字ボタンはそこではアイコンだけになる）の下に `Section` を並べ、中身は `KeyValues`・`EntityRow`・`Tag`・`Prose`。切り替えは見出しの直下に `Tabs`（1 つ目は「概要」）。`Tabs` は `PanelBody` の外、`PanelFrame` の直下に置く（アイコンとの間が 16px になる）。タブの下に切り替え・検索の帯を重ねない |

#### グラフの選び方

見せたいことでグラフを選ぶ。どれも 1 色の濃淡で描き、系列・区分ごとに色相を変えない。

値の確認口は読み取り用の図（`role="img"`）として名前を付ける。円の凡例は一覧の項目、ゲージは `meter`、選択する `TileMap` はボタンの役割を保つ。

全14種類のグラフは同じ吹き出しを使う。棒・点・帯・セル・タイル・ファネルの段にホバーするか Tab でフォーカスすると名前と値（指定した単位・内訳）を表示する。小さな印に正確に載せなくても読めるよう、散布図は点の近く、レーダーは輪の中のどこでも、一番近い点・項目を強調して吹き出しを出す。円・ドーナツは区分のホバーと凡例のフォーカス、`Gauge` は全体で値・範囲・目標（値が null なら「値なし」）、`Sparkline` は全体で推移の要約を表示する。ポインタとフォーカスがともに離れたとき、Esc、スクロール、窓のリサイズで閉じる。最初の Esc は吹き出しだけを閉じる。吹き出しは窓内に収め、スクロール枠や Dialog に隠さない。吹き出しの DOM はグラフと同じランドマーク・Dialog 内に保ち、切れ回避には popover の top layer を使う。既存の読み上げ用の要約・表・凡例・meter は維持する。

| 見せたいこと | 部品 |
|---|---|
| 時間の流れ（推移） | `LineChart`（面は `area`）、数字に添えるなら `Sparkline` |
| 期間・区分ごとの量を比べる | `ColumnChart`（縦）、名前が長い・項目が多いなら `BarList`（横） |
| 単位の違う 2 つの量を重ねる（件数と率） | `ColumnChart` の `line` |
| 内訳（期間ごと） | `StackColumns` |
| 全体に対する割合（区分が 5 つ以下） | `PieChart`（多ければ `BarList`） |
| 目標・上限に対する今の値 | `Gauge`（数だけでよければ `ProgressBar`・`Kpi`） |
| 増減の内訳（期首から期末へ） | `Waterfall` |
| 段ごとの減り方 | `Funnel` |
| 量の分布 | `ColumnChart` の `histogram`、区分ごとに比べるなら `BoxPlot` |
| 2 つの量の関係 | `ScatterChart`（3 つ目の量は `size`） |
| 複数の項目の釣り合い | `RadarChart` |
| 2 つの区分の組み合わせごとの量（曜日×時間帯、日ごとの活動） | `HeatMap` |
| 大きさと割合を同時に | `TileMap` |
