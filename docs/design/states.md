## 8. 状態の見せ方

グラフの値の確認口（図・メーター・円の凡例）は読み取り用とする。押せる部品のホバー・押している間の計測から除き、グラフ共通の吹き出しの表示・離脱・Esc・Tab を操作テストで確かめる。選択するタイルなどのボタンは通常どおり計測する。

| 状態 | 見せ方 |
|---|---|
| ホバー | 下の「ホバー」 |
| 押している間 | 下の「押している間」 |
| 選択（詳細を開いている） | 枠 `--pri` ＋ `--pri-ring`、一覧の行は `--pri-soft` の地 |
| フォーカス | `outline: 2px solid var(--pri)`。入力欄は枠 `--pri` ＋ `--pri-ring` |
| 無効・該当なし | `--ink-3` の文字で理由を書く（空欄にしない） |
| 押せない・入力できない（`disabled`） | 不透明度 0.45、ホバーで変えない |
| エラーのある欄 | 枠 `--danger`、欄の下に `--danger` の文とアイコン（`FormField` の `error`）。色だけで伝えない |
| 処理中 | 押した部品の中は `Spinner`（`Button` の `loading`）、領域は `Skeleton`、進みが測れるなら `ProgressBar` |
| 新しいデータへの入れ替え | トーストは出さない。今の表示のまま入れ替え、新しい時刻を `--pri-soft` の地で少しのあいだ強調する |

### 知らせの選び方

結果を伝える部品は、利用者が見ている場所と、操作を止める必要があるかで選ぶ（2026-10-30）。

| 伝えたいこと | 部品 | 消え方 |
|---|---|---|
| 入力の誤り | `FormField` の `error` | 直すと消える |
| 取り消せない操作の前の確認 | `ConfirmDialog` | 答えると閉じる |
| 画面全体の普段と違う状態（同期が止まっている） | `Notice` | 状態が戻ると消える |
| 操作の結果で、**画面を見ても結果がわからない**もの（保存した・送った・裏で失敗した） | `toast` | 数秒で消える（失敗は残す） |
| 操作の結果が画面で見えるもの（一覧の行が増えた） | 出さない | — |
| 消す操作 | 確認の代わりに `toast` の「元に戻す」（戻せるなら）。戻せないときだけ `ConfirmDialog` | — |

### ホバー

押せる・入力できるものは、マウスを載せると必ず見た目が変わる（2026-10-15。押せるかどうかをカーソルの形だけに頼らない）。変え方は部品の形で決め、同じ形の部品は同じ変え方にする。新しい部品を足すときも、下のどれかに当てはめる。

| 部品の形 | ホバー | 例 |
|---|---|---|
| 枠のある部品 | 枠 `--pri`（ボタンは文字も `--pri-ink`） | `Button`・`Select`・入力欄（`SearchField`・`TextField`・`TextArea`） |
| 主ボタン | 地 `--solid-hover` | `Button variant="primary"` |
| 地のない部品（行・項目・アイコン） | `--hover` の地（キーボードで選んでいる `Select` の選択肢も同じ地に枠） | `EntityRow`・`IconButton`・メニューの項目・`Select` の選択肢・`Menu` の項目・`Checkbox`・`RadioGroup`・`Switch`・`Accordion` の見出し・`Pagination` の番号・カレンダーの日・押せる `Kpi`・押せる `SettingRow`・テーマカラーの見本 |
| 地のない文字だけの部品 | 文字を濃く（`--link-hover`・`--pri-ink`） | `LinkButton`・`Crumbs`・`Brand` |
| 切り替えの選んでいない項目 | `--hover-strong` の地、文字 `--ink`（沈んだ地の上でわかる濃さ。選択中の淡い主要色の地と別の色） | `Segmented`・`Tabs` |
| 文中のリンク・値 | `--pri-soft` の地、文字 `--pri-ink` | `CopyText` |
| 詳細を開くカード・印 | `--shadow-hover` の影 | 押せる `Tag`・`MarkPicker` の見本 |
| 押し込まれた部品（押すと戻る） | 一段濃い `--pri-soft-2` の地、文字 `--pri-ink-2` | `Button active`・`active` の `Kpi`・開いている `SettingRow` |
| 絵の上で押す・動かすもの | 枠・輪など、その部品で目立つ線 | `TileMap` のタイル |

- 例外: 今選んでいて押しても変わらないもの（`Segmented`・`Tabs`・見本の選択中、今いる画面のメニュー項目、`Pagination` の今のページ、カレンダーの選択中の日、`Combobox` でキーボードで今いる候補、開いている先のカード）はホバーで変えない。入れ物（スクロールする領域・ボタンの並び）は数えない。
- 入力欄はフォーカス中はフォーカスの見せ方（8 章の表）が勝つ。押せないあいだ（`disabled`）は変えない。
- 動きは 6 章の 0.12〜0.16s。タッチの端末で残らないように、吹き出しなど出し入れするものは `@media (hover:hover)` の中に書く。
- 描いた画面の監査（アプリの `npm run ignite:audit`）が、画面ごとに押せる要素へマウスを載せ、見た目が変わらないものを拾う。例外を足すときは、ここと監査の除外の一覧を一緒に直す。

### 押している間

押せるものは、押している間（`:active`。マウスのボタン・指を離すまで）にホバーからもう一段見た目を進め、押したことが手応えとして伝わるようにする（2026-10-19、#78）。ホバーと同じく部品の形で決め、ホバーの次の段にする。新しい部品を足すときも、下のどれかに当てはめる。

- **大きさ**: 小さな部品（`Button`・`IconButton`・`Segmented`・`Tabs`・人名や取り消せるタグの × などのチップ・押せる `Tag`・テーマカラーとマーカー色の見本）は押している間 `--press-scale`（96%）に縮め、離すと `--press-back`（ばね）で戻す。広い面（一覧の行・メニューの項目・`Select` の選択肢・カード・`Kpi`・`SettingRow`）、文中の文字（`LinkButton`・`Crumbs`・`CopyText`）、絵の上の部品は縮めない（広い面が縮むと揺れて文字がにじみ、文中の文字が縮むと行が揺れる）。隣り合う小さな部品どうしの反応をそろえるための決まりで、Material 3 Expressive がボタンの仲間だけを押したときに形を変え、行・カードは色を重ねるのと同じ分け方（2026-10-20、#78。オーナー判断）。縮める量は 0.95〜0.98 の目安の中で、切り替えでも手応えがわかり、ボタンで大げさにならない 96% にする。縮める指定は `scale` で書き、部品の `transform` の動きと重ねない。
- **色**: 下の表（ホバーの次の段）。

| 部品の形 | 押している間 | 例 |
|---|---|---|
| 枠のある部品 | ホバーの枠・文字のまま、地 `--press` | `Button`・`Select`・枠のあるパンくず・人のカード・テーマカラーの見本・左メニューの開閉のつまみ |
| 主ボタン | 地 `--solid-press` | `Button variant="primary"` |
| 地のない部品（行・項目・アイコン） | `--press` の地 | `EntityRow`・`IconButton`・メニューの項目・`Select` の選択肢・押せる `Kpi`・押せる `SettingRow`・チェックの行 |
| 地のない文字だけの部品 | 文字 `--link-press` | `LinkButton`・`Crumbs`・`Brand` |
| 切り替えの選んでいない項目 | 色はホバーのまま（縮むだけ）。押した手応えは形で、選んだ結果は選択中の地のスライドで伝え、色の変化を重ねない（2026-10-20、#78） | `Segmented`・`Tabs` |
| 文中のリンク・値 | `--pri-soft-2` の地、文字 `--pri-ink-2` | `CopyText`・人名 |
| 詳細を開くカード・印 | 影を `--shadow-1` に沈める（白いカードは地も `--hover` に。影の差だけでは見えにくい） | 押せる `Tag`・カード・`MarkPicker` の見本 |
| 押し込まれた部品（押すと戻る） | `--pri-press` の地、文字 `--pri-ink-2` | `Button active`・`active` の `Kpi`・開いている `SettingRow` |
| 絵の上で押す・動かすもの | ホバーの線・輪を濃く・太く | `TileMap` のタイル・顔の並び |

- 押した瞬間に変え、離したらホバーと同じ動きで戻す（土台の `base.css` が押せる要素の `:active` の動きを 0 にする。0.12s かけて変えると、素早いクリックでは変わる前に離してしまう）。
- 例外はホバーと同じ（今選んでいて押しても変わらないもの・入れ物・`disabled`）。入力欄は押すとフォーカスの見せ方になるので、押している間の見た目を持たない。
- 押せる部品の中の押せる部品（カードの中の人名など）を押したときは、外側の部品を押している見た目にしない（`:active` は外側にも付くので、ホバーと同じく `:has(...:active)` で外側を戻す）。
- タッチの端末でも同じ見た目を出す（ブラウザ標準のタップの色は `base.css` で消し、二重に出さない）。
- 描いた画面の監査が、ホバーを確かめた要素を押している状態にして、ホバーのときと見た目が変わらないものを拾う。
