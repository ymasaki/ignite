### 見出しの段

見出しは意味で 3 段に分け、段ごとに 1 つの見た目にする。同じ意味の見出しを場所ごとに作り分けない（2026-09-29）。

| 段 | 部品 | 意味 | 見た目 |
|---|---|---|---|
| 区切りの帯 | アプリの一覧の区切り | 一覧・画面の中の大きな区切り | `--panel-2` の地の帯（13px・太字、件数は灰色） |
| まとまりの見出し | `Section` | 内容のひとかたまり（詳細パネルの区切り、横に並べたまとまり） | 14px・太字、下に `--pri-soft-2` の 2px の線、件数は灰色 |
| 小見出し | `SubHeading` | まとまりの中の行の小分け | 12px・太字・`--ink-2`、線なし、件数は灰色 |

- 枠のあるカード（`ChartCard` など）の見出しは、枠が区切りを示すので線を引かない。
- まとまりの中をさらに分けるときは `SubHeading`。`Section` を入れ子にしない。

### 状態で表示が変わる部品

押す・開く・読み込むなどで表示が変わる部品は、状態が変わっても同じ部品・同じ CSS の箱のまま、中身だけを替える。

- 状態ごとに別の部品・別のクラスで作り直さない。違いは部品の引数（例: 区切りの帯の `back`・`sticky`）で出す。
- 高さ・余白・行の高さを状態ごとに上書きしない。固定の高さや中央寄せで合わせない（中身の行の高さで決まる箱に任せる）。
- 付け足す中身（パンくず・件数・戻るリンク・タグ）は元の文字と下端をそろえる（`align-items: baseline`、`font-size`・`line-height` は受け継ぐ）。
- 狭い幅の決まりなど元の箱にかかる規則が、付け足した状態にも同じようにかかる作りにする（幅の問い合わせの基準の要素も同じにする）。
- 描いた画面の監査（アプリの `npm run ignite:audit`）が、状態を切り替える前後で箱の上端・高さと最初の文字の左・下端を比べる。状態で表示が変わる部品を足したら、監査の切り替えの一覧にも足す。
