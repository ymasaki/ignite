## 2. 色

`src/styles/tokens.css` のトークンだけを使う。色コードを直接書かない（例外は「アバター色」だけ。アプリ固有の色はアプリのテーマにトークンとして足す）。値は既定（スキン `red`・ライト）のもの。

| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#f6f6f7` ＋主要色 1.5% | 画面の地 |
| `--panel` | `#ffffff` | カード・パネル・ボタンの地 |
| `--panel-2` | `#fafafb` ＋主要色 1% | 一段沈んだ地（表の見出し、切り替えの入れ物） |
| `--hover` | `#f5f5f6` ＋主要色 2%（ダークは `#2f2f34` ＋ 3%） | 地のない部品のホバーの地（8 章「ホバー」。白い地の上でわかり、広い面（KPI・月の切り替え）でも重くならない濃さ。その上の文字は `--ink-3` でも 4.5 以上） |
| `--hover-strong` | `#f0f0f2` ＋主要色 2.5%（ダークは `#35353b` ＋ 3%） | 沈んだ地（`--panel-2`）の上の項目のホバーの地（切り替え・タブの選んでいない項目。`--hover` では地と見分けにくい） |
| `--hover-layer` | `#141428` ＋主要色 3% を 6% の濃さで重ねる（ダークは白 ＋ 3% を 8%） | 色のついた地の上にも重ねるホバーの半透明の層（`DataTable` の行）。白い地の上では `--hover-strong` とほぼ同じ濃さで、割合の色を消さずに少し沈める |
| `--press` | `#eeeef0` ＋主要色 2.5%（ダークは `#38383d` ＋ 3.5%） | 押している間の地（8 章「押している間」）。`--hover` の次の段で、その上の `--ink-3` が 4.5 を保てる濃さまで（これより濃いグレーは作れないので、`--hover-strong` の次の段は持たない） |
| `--line` / `--line-2` | `#e2e2e3` / `#c9c9cb` ＋主要色 2〜2.5% | 区切り線 / 入力欄・ボタンの枠 |
| `--edge` | `#b0b0b2` ＋主要色 3% | 要素どうしをつなぐ線 |
| `--ink` / `--ink-2` / `--ink-3` | `#3c3c43` / `#67676c` / `#69696e` ＋主要色 1.5〜3% | 本文 / 補足 / ラベル・件数 |
| `--pri` | `#f04600` | 主要色（選択の枠、強調、アイコン、バッジ） |
| `--pri-soft` / `--pri-soft-2` | `#ffece7` / `#ffdad0` | 選択・ホバーの薄い地（50 番と 100 番の間。50 番は白の上でほとんど見えない）/ より強い選択の地（100 番） |
| `--pri-ink` | `#c13600` | 薄い主要色の地の上の文字 |
| `--thumb` / `--pri-ink-2` | `--pri-soft-2` / `#9a2900` | 切り替え・タブの選択中の地と文字（文字は 700 番。`green` は選択が弱く見えるので地を green/200、文字を green/800） |
| `--pri-ring` | `rgba(240,70,0,.18)` | 選択・フォーカスの外側のにじみ（`box-shadow: 0 0 0 3px`） |
| `--on-pri` | `#ffffff` | `--pri` の地の上の大きな数字・アイコン（文字をのせるベタ塗りは `--solid`） |
| `--solid` / `--solid-hover` / `--on-solid` | `#c13600` / `#9a2900` / `#ffffff` | ベタ塗りの地（主ボタン・バッジ・選択中の小さな札）とその上の文字。白い文字が読める濃さ（4.5:1 以上が目安）の段を使う: `red` は red/600、`blue` は blue/600、`green` は green/700。濃い段は主要色とトーンが違って浮くので、面積の小さいものにだけ使う |
| `--solid-bright` | `--pri` と `--solid` を 55:45 で混ぜた色 | 白いアイコンをのせる明るめのベタ塗り（押した KPI のアイコン）。`--solid` より主要色に近く浮きにくい。白いアイコンとの比は 3:1 以上（文字はのせない） |
| `--link` / `--link-hover` | `#c13600` / `#9a2900` | 文字だけのリンク（`LinkButton`、文中のパンくず） |
| `--solid-press` / `--link-press` / `--pri-press` | `--solid-hover`・`--link-hover` に黒を 22% / `--pri-soft-2` に主要色を 14%（ダークは `--link-hover` に白を 40%、`--panel` に主要色を 38%。コントラストを強くしたときの `--pri-press` は、ライトが主要色 7%、ダークが 28%） | 押している間の主ボタンの地 / 文字だけのリンクの文字 / 淡い選択の地（その上の文字は `--pri-ink-2`）。ホバーの色から混ぜて作るので、スキンごとに値を持たない |
| `--focus` / `--focus-ring` | `--pri` / `--pri-ring` | キーボードのフォーカスの枠、入力中の欄の枠とにじみ |
| `--tip` / `--on-tip` | `--ink` / `#ffffff` | 吹き出し（ツールチップ）の地と文字 |
| `--chart-1`〜`--chart-5` | 主要色の 500・300・200・100・50 | グラフ・表の濃淡（1 がいちばん濃い）。グラフの部品は `--pri` を直接読まない |
| `--ok-soft` / `--ok-ink` | `#cbf3e3` / `#007357` | 肯定のタグ |
| `--warn` / `--warn-soft` | `#946000` / `#fff6ec` | 注意（ダミーデータ表示など） |
| `--danger` / `--danger-soft` | `#c01f3a` / `#ffecee`（ダークは `#ff8a98` / `#4a1a22`） | エラーの文・枠、危険な操作の項目 / 危険の知らせ・タグの地 |
| `--danger-solid` / `--danger-solid-hover` / `--danger-solid-press` / `--on-danger` | `#c01f3a` / `#9d1830` / ホバーに黒を 22% / `#ffffff` | 取り消せない操作のボタン（`Button variant="danger"`）。スキンで変えない |
| `--hl` | `#ffe08a` | 検索語のハイライト |
| `--hl-line` | `#f2a31b` | 検索語の下線 |
| `--scrim` | `rgba(0,0,0,.3)` | 引き出しの背面 |

- **アバター色**（`.c1`〜`.c6`）：顔写真がないときの頭文字の地。見分けるための例外で、ここだけ 6 色を使う（スキン・モードで変えない）。
- **マーカー色**（`--mark-1`〜`5` と枠の `--mark-N-line`。黄・緑・青・紫・桃）：利用者が自分で選んで塗るハイライト。画面の側が区分を塗り分けるのではなく、利用者の書き込みなので 1 色の原則の例外にする。スキンでは変えず、ダークの値は `dark.css`。塗る部品は `[data-mark="N"]` が置く `--mk`（地）・`--mk-line`（枠）を読む。色だけで伝えないよう、選ぶボタンと塗ったものの読み上げの名前に色の名前・「コメントあり」などを入れる。地の上の `--ink`・`--ink-2`・`--ink-3` は 4.5 以上（`contrast.ts`）。
- **意味の色**（`--ok-*`・`--warn*`・`--danger*`）：区分の塗り分けでなく、状態の良し悪しだけに使う。これは原則 2「1 色でまとめる」の例外ではなく別の役割で、主要色に置き換えない。危険の赤は主要色が赤のスキン（`red`）では色相が近いので、**色だけで伝えない**（アイコンか文字を必ず添える。`FormField` のエラー・`Notice`・`Toast` は部品が添える）。`--danger` を使うのは、エラーと取り消せない操作だけ（「注意」は `--warn`）。
- 地の上の文字は、地と組のトークンを使う（`--pri` の上は `--on-pri`、`--solid` の上は `--on-solid`、吹き出しは `--on-tip`）。白を決め打ちしない（スキン・ダークモードで組が変わる）。

### コントラスト

文字と地、部品と地の色は、読める・見分けられるコントラストを保つ（WCAG 2.x の AA）。どのスキン・表示モードでも満たす。

| 対象 | 下回らない比 |
|---|---|
| 文字（大きさによらず。ラベル・件数・タグ・ボタンの文字を含む） | **4.5** |
| 文字でないもの（アイコン・選択の枠・フォーカスの枠・グラフの線と棒）と、主要色の地の上の大きな数字 | **3** |

- 決まりの正本は `src/contrast.ts` の `CONTRAST_RULES`（前に出る色と地のトークンの組ごとに、下回らない比と使いどころ）。色のトークンを足す・値を変える・新しい組み合わせで使うときは、ここに組を足す。
- デザインの監査（`npm run ignite:audit`）が、全スキン × ライト・ダークで、実際に描いた色（`color-mix` の結果）の比を測る。下回れば監査が失敗する。
- 設定の「コントラストを強く」（12 章）では、文字 **7**・枠と区切り（`--line-2`）**3**・スキンの例外なし（`contrastRulesFor(true)`）。値は `styles/assist.css`。
- 色の選び方の決まり（ここから出た）:
  - 白い文字をのせるベタ塗り（`--solid`）は、主要色そのものではなく濃い段（600〜700 番）。主要色（500 番）の地にのせるのは、大きな数字・アイコンだけ（`--on-pri`）。
  - 薄い主要色の地の上の文字は、地の濃さに合わせて段を選ぶ（`--pri-soft` の上は `--pri-ink`、`--pri-soft-2`・`--thumb` の上は `--pri-ink-2`）。
  - いちばん薄い文字（`--ink-3`）も 4.5 を満たす濃さにする（元の色 `#7b7b7f` は白の上で約 4.2 だったので、選択中の薄い主要色の地の上でも満たす `#69696e` に下げた）。
  - ホバーで色を変える文字は `--pri-ink`（`--pri` は文字には薄い。枠・アイコンだけに使う）。
- 色のほかに、キーボードで動かしている場所を見えるようにする: プルダウンの選択肢はフォーカスの枠を出す（地だけではホバーと見分けられない）。`data-tip` の吹き出しは、ホバーに加えてキーボードのフォーカスでも出す。
- **例外（緑のテーマのライトだけ）**: ブランドの緑 `#00c093` は明るく、白い地の上で約 2.3 しかない。アイコン・選択の枠・グラフに限って許す（`CONTRAST_RULES` の `except`）。これらは色だけに頼らない（形・地・数字でも示す）。文字とフォーカスの枠には例外を置かず、濃い段（`--pri-ink` は green/700、`--focus` は green/600、`--on-pri` は green/900）を使う。
- 対象にしていないもの: 区切り線・カードの枠・入力欄の枠（`--line`・`--line-2`・`--edge`。白の上で 1.7〜2.2）。装飾の線として扱い、入力欄・ボタンは地の違いと文字でも示す。入力欄の枠まで 3 を求めるなら、枠の色を別のトークンに分けて濃くする（未着手）。

### スキンとダークモード

色のトークンの値を差し替える仕組み。`<html data-skin="名前" data-mode="light|dark">` の値で決まり、大きさ・動き・部品の形は変えない。部品の CSS にスキン・モードごとの分岐を書かない（足りなければ役割のトークンを足す。例外は強制カラーだけ。12 章）。

- 地・線・文字は無彩色のグレーに、主要色をわずかに混ぜて寄せる（`color-mix`。地で 1.5%。色がのって見えない、さりげない量にとどめる）。リンク・グラフも 1 色の原則を優先して主要色でまとめる。
- **スキン**（テーマカラー）は主要色まわり（`--pri` 系・`--link`・`--chart-*`）だけを差し替える。

| スキン | 主要色 `--pri` | 定義 |
|---|---|---|
| `red`（既定） | `#f04600` | `tokens.css` |
| `blue` | `#0080ee` | `skins/blue.css` |
| `green` | `#00c093`（明るいので、上の数字・アイコン `--on-pri` は濃い緑、フォーカスの枠は green/600） | `skins/green.css` |

  ブランドの黄（`#ffaa00`）は読みにくいので置かない。
- **ダークモード**は `dark.css`（スキンの後に読む）。地・線・文字・影を暗くし（主要色をわずかに混ぜるのは同じ）、ベタ塗りはライトと同じ濃い段。表示モードは ライト / ダーク / 自動（`auto`。端末の設定に合わせる。`<html data-mode>` には決まったほうを書き、選び方は `data-mode-pref`）。主要色そのものはライトと同じで、薄い地とグラフの濃淡は主要色を暗い地に混ぜて作る（`color-mix`。スキンを足しても濃淡がそろう）。薄い地の上の文字とリンクだけ、スキンごとに明るい色を書く。
- **アプリのマーク**（左メニューの `Brand` の `.brand-mark`。SVG で描いたもの）は `--pri` で塗るので、スキンに従う（起動画面のマークも同じ）。
- **Ignite 自身のロゴ**は `docs/logo/`。`ignite-mark.svg` は炎の形だけ（`currentColor`。アプリの中ではスキンに従う）、`ignite-icon.svg` は赤の地に白の炎（ファビコン・文書。地の赤 `#be141b` はロゴの色で、スキンで変えない）。
- **切り替え**は `src/skin.ts`。アプリは起動時に `startTheme(URL のパラメータ)` を呼び、左メニューの下に `SettingsButton`（「設定」）を置いて、設定の画面に `ThemeSettings`（テーマカラーは実際の色の丸、表示モードはアイコン付きの `Segmented`。切り替えは画面全体を 0.3s で入れ替える）を出す。ほかの場所から切り替えるときも、`withFade(() => setTheme(next))` で同じフェードにする（`setTheme` は当てるだけで動かない。起動時やサーバーの値の反映はフェードしない）。選んだものは端末に覚え（`ds.skin`・`ds.mode`）、HTML の最初の小さなスクリプトが最初の描画から当てる（読み込み中に色が切り替わって見えないように）。URL の `?skin=blue&mode=dark` でも切り替わる。
- スキンを足すとき: `skins/<名前>.css` に `:root[data-skin="名前"]` で主要色まわりを書き、`dark.css` に明るい文字の色を足し、`styles/index.css` で読み、`skin.ts` の `SKINS` と `ThemeSettings` の選択肢に足す。アプリ固有のトークンは、アプリのテーマに同じセレクタで書く。
