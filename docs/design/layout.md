## 5. 余白と大きさ

- 余白は 4 の倍数を基本にする（4 / 8 / 12 / 16 / 24 / 32。トークンは `--space-1`〜`--space-6`。部品の CSS で使える。検査はしない）。カードの内側は 10〜18px、パネルの内側は 18px。例外は下の「外側の余白」（窓の大きさでなめらかに変わるので端数になる）。
- 画面の段組み（ヘッダーの下の段）の余白は `--shell-x`（左右）・`--shell-top`（ヘッダーから最初の段）・`--shell-gap`（段の間）・`--shell-bottom` で決める。KPI の帯のない画面も同じ変数で、ヘッダーから内容の枠までをそろえる。ヘッダーの左右の余白も `--shell-x`（内容と左端をそろえる）。
- **外側の余白は窓の大きさに比例させる**（2026-09-29）。余白の自然な大きさは全体の大きさとの比で決まるので、外側の余白（上の 4 つと、内容と詳細パネルの間 `--shell-gap` + 2px）は区切りで段を付けず、上限と下限のあいだを窓の幅・高さに合わせてなめらかに変える（`tokens.css` の `clamp()`。`@property` で長さとして登録し、計算済みの px で読める）。横の余白は幅で、縦の余白は幅と高さの小さいほうで決める。
- **上限は小さめに止める**（2026-09-30）。大きな窓で余白だけが育つと、主役（内容の枠）に回せる幅・高さが減る。上限は部品の中の余白（カードの内側 10〜18px）を超えない大きさにし、左右は 12px、最後の段の下は 8px で止める（下を左右より広くすると、内容の枠が浮いて見える。2026-10-15。2026-11-07 に下を 12 → 8px、ヘッダーから最初の段を 8 → 4px へ詰め、主役を広げた）。左右は窓を狭めると最初に詰める余白で、パネルを詰める・左メニューを畳む前に下限の 8px になる。ヘッダーの左だけは、左メニューのつまみ（境目から 12px はみ出す）をよけて 20px 以上にする。

  | 変数 | 下限 → 上限 | 何で決まるか |
  |---|---|---|
  | `--shell-x` | 8 → 12px | 幅 1180 → 1440px（1180px 以下は 8px。詳細パネル・左メニューの区切りの計算がこの下限を使う） |
  | `--shell-gap` | 8 → 10px / 6 → 10px | 幅 860 → 1440px と、高さ 500 → 800px の小さいほう |
  | `--shell-top` | 2 → 4px | 高さ 500 → 800px |
  | `--shell-bottom` | 6 → 8px | 高さ 500 → 800px |
  | `--shell-head-top` | 10 → 12px / 6 → 12px | ヘッダーの上。幅 375 → 1180px と、高さ 500 → 800px の小さいほう |
  | `--shell-head-bottom` | 4 → 6px / 0 → 6px | ヘッダーの下。幅 860 → 1180px と、高さ 500 → 800px の小さいほう |
  | `--shell-head-gap` | 8 → 16px | ヘッダーの画面名の組と右の操作の間。幅 375 → 1180px |
  | `--shell-head-row` | 8 → 10px | ヘッダーを 2 段に組んだときの段の間。幅 375 → 860px |
  | `--shell-title-gap` | 8 → 14px | 画面名と範囲の選択（表示する範囲の切り替え）の間。幅 375 → 1180px |
  | `--bar-y` | 8 → 10px / 6 → 10px | 内容の上の帯（`ScreenBar`）の上下。幅 375 → 860px と、高さ 500 → 800px の小さいほう |
  | `--bar-x` | 10 → 14px | 帯の左右。幅 375 → 860px |
  | `--bar-gap` | 8 → 14px | 帯の操作の間。幅 375 → 860px |
  | `--bar-row` | 8 → 10px | 帯を折り返した段の間。幅 375 → 860px |

  区切り（860px・600px など）で変えてよいのは組み方（2 段に組む・引き出しにする・ボタンにまとめる）だけで、余白の値は区切りで変えない。帯や道具の段など、画面の枠の中の段の余白を窓で変えるときも、区切りでなく `clamp()` でなめらかに変える（`@media` の `max-width` / `max-height` の中で余白を px の値で書くと `ignite check` が止める。組み方が変わって現れる部品は、区切りの外に書くか `design-ok` で理由を書く）。

  部品の中の余白（ボタン・一覧の行・切り替え・カードやパネルの内側）は固定する。部品の大きさは窓で変わらないので、比で決まる余白も変わらない（押しやすさと、画面ごとのそろい方を保つ）。部品が狭いときは部品の修飾（`dense` など）で詰める。
- 操作できる部品の高さ：ボタン 34px（ヘッダーの入力欄・ボタンは `--control-h` 40px）、一覧の行 36px 前後。
- アイコンは Tabler（`@tabler/icons-react`）。大きさ 14〜18px（空の状態の案内だけ 22px）、線の太さ 1.7〜1.8。
