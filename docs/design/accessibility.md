## 12. アクセシビリティ

目標は WCAG 2.2 AA と WAI-ARIA Authoring Practices（APG）。**マウスで見る人の見た目と操作を変えずに**、読み上げソフト・キーボード・音声入力・拡大で使える形にする。見た目が変わる対応（動きを止める・文字を大きくするなど）は、既定を変えずに設定で選べるようにする。

- **ランドマーク**：`AppShell` が左メニュー（`aside`「メニュー」）・本体（`main`）・詳細パネル（`section`「詳細」）を描く。内容はどれかの中に置く。
- **名前**：押せるものには見えている文字か `aria-label` の名前を付ける。見えている文字があるときは、名前がその文字を含むようにする（2.5.3）。アイコンだけのボタンは `aria-label` と `data-tip` を付ける（動作が明らかな前後送り・増減は `aria-label` だけ。1 章）。
- **部品の役割**：1 つを選ぶ切り替えは `Segmented`、タブは `Tabs`（roving tabindex、←→ / Home / End）、選択は `Select`・`Combobox`（`aria-activedescendant`）・`RadioGroup`、操作の一覧は `Menu`（`role=menu`）、日付は `DatePicker`（`role=grid`）、重ねて出すものは `Popover`（Esc で閉じて開いた元へ戻る）、重ねるパネルは `Drawer`（modal。開いているあいだ背面は `inert`）、答えを待つ窓は `Dialog`（ブラウザの `<dialog>`）。自前の役割を書かず、部品を使う。
- **入力欄の名前**：入力の部品は `FormField` の見出しか `label` で名前を持つ。placeholder を名前の代わりにしない。エラーは `aria-invalid` と `aria-describedby` で欄に結び付ける（`FormField` が行う）。
- **知らせる**：件数・絞り込みの結果・読み込みの完了・コピーなど、画面の変化で目で見てわかることは `announce()` で読み上げにも知らせる（4.1.3）。エラーは `{ assertive: true }`。`toast` は自分で知らせる。`Dialog` が開いているあいだは、知らせる場所を窓の中へ移す（窓の外は読み上げの対象外になるため）。差し込んだばかりの `role=status` は読まれないことが多いので使わない。
- **フォーカス**：押したものが消える操作（閉じる・切り替える）では、フォーカスを開いた元か次の場所へ移す（`useReturnFocus`・`keepFocus`）。フォーカスを body に落とさない（2.4.3）。
- **スクロールする領域**：はみ出して送れる枠は `useScrollFocus` でキーボードでも送れるようにする（はみ出したときだけ Tab で止まる）。
- **押す面**：24×24px 以上か、隣との間を空ける（2.5.8）。見た目を大きくできないときは、余白と負のマージンで押せる範囲だけを広げる（`.crumbs button`）。例外は、顔アイコンを詰めて並べるとき（`AvatarStack` の `fit` で間を 4px より詰めた `.tight`）だけ。押せる範囲は 24px に広げるが重なるので、同じ人を同じ画面の押しやすい一覧（詳細パネルのメンバー）から開けることを条件に、2.5.8 の「同等の操作がある」例外とする（オーナー判断、#88）。監査はこの顔の target-size だけを数えない。
- **色だけで伝えない**：変わった・選んだ・良し悪しを色だけで示さず、読み上げ用の文字（`.sr-only`）か形を添える（1.4.1）。
- **グラフ**：形で見せる値は、読み上げにも文字で渡す（1.1.1。見た目の「表で見る」切り替えは置かない）。`ChartCard` の名前は見出し（既定 h2、`level`）。折れ線・推移の線は範囲と最初・最新・最小・最大の要約を名前にし、点ごと・期間ごとの値は `.sr-only` の表（`SrTable`）で渡す。縦棒・滝・箱ひげ・散布図・レーダー・ヒートマップも、要約の名前と同じ見えない表で渡す。円は見える凡例（名前・数・割合）をそのまま読ませ、ゲージは `role="meter"` で値と範囲を渡す。顔の並び（`AvatarGroup`）は名前の一覧。`.sr-only` を置く部品は位置の基準（`position:relative`）を持たせ、スクロールする枠の外にはみ出させない。
- **動き**：端末の「視差効果を減らす」（`prefers-reduced-motion`）では、移動・拡大縮小・開閉・フェードを止め、回り続ける動きは 1 回で止める（`base.css`）。JS の動きは `reducedMotion()` を見る（`withFade` は見てすぐ切り替える）。出てからしばらくで消える知らせを CSS の動きで消すときは、動きを止めても見せる時間を保つ（長さを一律に縮めると、最後の消えた姿だけが残って一度も見えない。`SideStatus` の「更新しました」は、薄れさせずにすぐ出し、同じ時刻ですぐ消す）。
- **強制カラー**（Windows のハイコントラスト。`@media (forced-colors: active)`）：端末が文字・地・線の色を自分の配色に置き換え、影を消す。地の色や影だけで示す状態は消えるので、選んだ状態は系統色の `Highlight`（地）・`HighlightText`（その上の文字）で塗り、輪郭は線、フォーカスは `outline` で出す。系統色の地の上に文字を書く要素は `forced-color-adjust:none` で、ブラウザが文字の後ろに敷く地の色の板を止める（板があると白い板に白い文字になる）。対応済み: `Switch`・`Checkbox`・`RadioGroup` の選んだ状態、`Segmented`・`Tabs`・`Pagination` の選択中、入力欄（`.field`）のフォーカス。地の色や影で状態を示す部品を足したら、ここに足し、操作テスト（`catalog/e2e/parts.e2e.ts` の強制カラー）でも確かめる。
- **表示の補助の設定**（`assist.ts`・`styles/assist.css`・設定の画面の `AssistSettings`）：見た目の変わる対応は、既定を今の見た目のまま、選んだ人にだけ効かせる。どれも `<html>` の属性で当て、部品は属性を見ずにトークン・クラスだけで描く。
  | 設定 | 誰のため | 何が変わるか（デザインを崩さない工夫） |
  |---|---|---|
  | 動きを減らす（端末に合わせる / 減らす） | 前庭障害・片頭痛・てんかん・集中の途切れやすい人 | 移動・拡大縮小・開閉・フェードを止める。端末の「視差効果を減らす」でも同じ |
  | コントラスト（端末に合わせる / 強く） | 色弱・ロービジョン・明るい場所で使う人 | 文字は 7:1（AAA）、枠と区切りは 3:1。地とブランドの色味は残し、文字と線だけを濃くする。主要色の文字は主要色の明るさだけを固定して作る（`oklch(from var(--pri) L c h)`。どのスキンでも同じ濃さ）。フォーカスの枠を 3px に。端末の「コントラストを上げる」でも同じ |
  | 文字の大きさ（標準 / 大 1.125 / 特大 1.25） | 弱視・年配の人・高解像度の画面の人 | 文字だけを大きくし、枠の寸法・余白は変えない（ブラウザの拡大と違い、組織図の広さを保つ）。部品の `font-size` は目盛りのトークン `--fs-*` だけで書く（`ignite check`）。顔アイコンの頭文字は丸に合わせて変えない |
  | フォーカスの枠（キーボードのとき / いつも） | キーボード・スイッチで操作する人、マウスと行き来する人 | マウスで押したあとも枠を出す |
  | リンクの下線（なし / あり） | 色で押せる文字を見分けにくい人 | 細く・少し離し・文字の色を薄めた下線（ホバーで濃く）。押せる文字は `.linkbtn`・パンくず・`data-link` を付けた要素 |
  | 1 文字のショートカット（使う / 使わない） | 音声入力の人（WCAG 2.1.4） | F・[ を切る。⌘K / Ctrl+K など修飾キー付きは残す |

  - 「キーボードのとき」はマウス・タッチ操作の直後に枠を出さない。入力欄から詳細見出しなどへフォーカスを移す場合も同じ。キー操作に戻ると枠を表示する。入力中の欄の枠とにじみは操作方法によらず保つ。

- **検査**：デザインの監査（`npm run ignite:audit`）が、全画面 × 幅 × 表示モードを業界標準の自動検査 axe-core（WCAG 2.2 AA とベストプラクティスの規則）で確かめ、違反があれば失敗する。表示の補助を選んだ状態も測る: 文字「特大」で主な画面（文字の目盛りは倍率を掛けて測り、はみ出し・1 行の値・ボタンの高さはそのまま）、コントラスト「強く」で全スキン × ライト・ダークの色の組（`contrastRulesFor(true)`: 文字 7・枠の組を足し・緑の例外なし）と axe。axe に見えない動きのある操作（フォーカスの行き先・知らせる文・キー操作）は E2E で確かめる（`catalog/e2e/parts.e2e.ts`）。
