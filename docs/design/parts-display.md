## 7. 部品（移動・重なり・表示）

| 部品 | ファイル / CSS | 使いどころ・決まり |
|---|---|---|
| `Tabs` | `Controls.tsx` / `controls.css` | パネル内の表示の切り替え。`count` で件数。`fit` で置き場所の幅を名前の長さに合わせて配る（長い名前を切らない） |
| `Menu` | `Navigation.tsx` / `navigation.css` | ボタンから開く操作の一覧（値を選ぶなら `Select`）。ボタンは文字か `iconOnly`。項目は `icon`・`danger`（文字が `--danger`）・`disabled`・`separator`。↑↓・Home・End で移り、押せない項目は飛ばす。実行すると閉じて元のボタンへ戻る |
| `Pagination` | 同上 | 長い一覧のページ送り（読み込み中も今のページを保つ）。最初・最後・今の前後の番号を残す。枠が 320px 以下なら「3 / 20」にする。1 ページなら出さない |
| `Accordion` | 同上 | 見出しを押して開閉するまとまりの並び。既定は同時に 1 つ、`multiple` で複数。詳細パネルや設定の補足に使い、主役の内容を隠さない |
| `Dialog` / `ConfirmDialog` | `Dialog.tsx` / `overlay.css` | 操作を止めて答えを待つ窓 / 取り消せない操作の確認。詳細を見せるだけなら詳細パネルを使い、窓の中に窓を重ねない。スマホ幅は下からのシート。主ボタンは右端。`ConfirmDialog` の `title` は「〜しますか」で何が起きるかを書き、確定は動詞（「はい」にしない）。`danger` のはじめのフォーカスは取り消しの側。`dismissable` を切ると Esc・外側のクリックで閉じない（Esc を続けて押すとブラウザが窓を閉じるが、部品が開き直す）。外側のクリックで閉じるのは、押すのも離すのも外側のときだけ（中で文字を選んで外で離しても閉じない） |
| `Toast` | `Toast.tsx` / `overlay.css` | `toast(文, { tone, action, duration })` で出す操作の結果の知らせ。部品は `Toaster`（`AppShell` が置く）。8 章「知らせの選び方」。右下（スマホ幅は下）に 3 つまで。`info` と `ok` は 5 秒（`action` があれば 8 秒）で消え、載せている・フォーカスがあるあいだは止まる。`danger` は × で閉じるまで残る（4 つ目が出ると、種類によらず古いものから消える）。`action` は 1 つだけ（「元に戻す」など）。× や `action` で閉じた知らせにフォーカスがあれば、隣の知らせの ×、なければ知らせに入る前の場所へ移す。`Dialog` の背面に出るので、窓を閉じてから出す |
| `Spinner` / `ProgressBar` | `Progress.tsx` / `progress.css` | 待ち時間の読めない処理の回転（ボタンの中・小さな更新。領域の読み込みは `Skeleton`）/ 進み具合の棒（`value` は 0〜100、`null` は測れない処理。`showValue` で %） |
| `Steps` | 同上 | 順に進む手続きの今いる段階。枠が 600px 以下なら縦に並ぶ。段を押して戻る操作は持たない |
| `Popover` / `Drawer` | `Controls.tsx` / `controls.css` | 小さなパネル（外側のクリック・Esc で閉じる。開いている間は呼び出し口の吹き出しを出さない。下・右で切れるなら反対側へ開き、上下どちらにも入らなければ窓の中央に重ねて中でスクロールする）/ 狭い画面のパネル（右から、スマホ幅は下から）。`peek` と `minimized` で下の 1 行に畳む（5 章「操作の結果を見える場所に出す」。ふつうは `AppShell` の `useShell().revealMain()` が畳む） |
| `Tag` / `Chip` / `Badge` | `Chip.tsx` / `chip.css` | 状態の印（`variant`: `accent` / `dashed` / `ok` / `warn` / `danger`。良し悪しのある状態だけ意味の色）/ × で取り消せるタグ（絞り込みの差分）/ ボタンの中の数字（通知・未処理にだけ使う。消えない数に付けない）。`count` を渡し、0 なら幅を畳んで隠す（出し入れ・数の変化でボタンの幅がなめらかに動く） |
| `Avatar` | `Avatar.tsx` / `avatar.css` | 顔アイコン（`xs` 20 / `sm` 26 / `md` 32 / `lg` 44 / `xl` 72px）。頭文字・画像・色の番号を受け取る。写真を読み込むあいだは淡い丸、読めたら 0.35s でフェードイン。重ねて並べるときは `.avstack`（縁・薄さは置き場所で `--av-ring` / `--av-opacity`、最後の 1 つは `-last`）。選んでいる・ホバーした顔の輪は、どこでも `--av-ring-on`（地の色のすき間 1px ＋ 主要色 1px） |
| `AvatarStack` / `fitAvatars` / `keepVisible` | 同上（決め方は `avatarFit.ts`） | 重ねた顔の列。顔は `render` で描き、`onPick` で押せる、`activeId` の顔は印を付けて「+N」に隠さない。`fit` は置き場所の幅に合わせ、間を空ける → 重ねる → 「+N」の順に詰める。押せる顔は押せる範囲 24px を残す分だけ重ねる（`pressOverlap`） |
| `AvatarGroup` | 同上 | 顔アイコンの並び（折り返して並べる。`stack` は少し重ねて 1 行）。ホバーで `tip`、`max` を超えた分は「+N」、`muted` は薄く出す |
| `IconBox` | 同上 | 人以外のアイコンの箱（`md` 28 / `lg` 40 / `xl` 72px） |
| `EntityRow` / `Highlight` | `List.tsx` / `list.css` | 一覧の 1 行（`lead`・`title`・`sub`・`trailing`。`size="lg"` は格子に並べる大きい行）/ 検索語の強調。上下のつながり（レポートライン）は `.chain`、枝分かれの行は `branch` |
| `Kpi` / `KpiBand` | `Kpi.tsx` / `kpi.css` | KPI の 1 枠（アイコン・ラベル・数字）。`onClick` で押せる枠、`active` で押し込まれた状態、`decimals` で小数（平均の年数など）。`value: null` は「—」にし、0 と欠損を区別する。`sub` は数字の下の比較（`Delta` と前の期間の値）。`Delta` は前の期間との差（`better` で良くなった差を `--ok-ink`、悪くなった差を `--warn`、0 は薄い文字。比べる相手がなければ出さない）。帯は 2 通り: `.kpis`（独立した値。入らなければ段を足して折り返し、段の間の線は影。帯が 520px 未満なら枠を段の幅いっぱいにして縦にそろえる）/ `KpiBand`（まとまり `groups` を渡すと、入らないまとまりを `summary` の 1 枠にまとめ、入るもののうち幅をいちばん使う組み合わせで出す。枠はなめらかに出し入れ。`resetKey` で画面を切り替えた直後は動かさない。1 段で左詰め。まとめた枠は押すと下に一覧（`.kpi-pop`。1 つずつの枠を縦に並べる。外側を押す・Esc で閉じる）を開き、そこで枠を押せる。`active` の枠があるまとまりは、まとめた枠の代わりにその枠を帯に残し、押すと同じ一覧を開く（選び直す・もう一度押して戻す）） |
| `DataTable` | `Table.tsx` / `table.css` | 値の表（見出しは12px、本文は13px）。列・行の値だけを受け取り、先頭列は行の見出し。割合のセルは `ratio`（0〜1）で主要色（`--chart-1`）の濃淡を5段階にする。欠損は「—」。横幅が足りなければ表の中だけをスクロールする。`dense` はカードの中に並べる表（セルの余白 12×16 → 8×10px）。並べ替えは列に `sortable`、`sort` と `onSort`（並べ替えた行を渡すのはアプリ）。選択は `rowKeys`・`selected`・`onSelect`（先頭に `Checkbox` の列。すべて選ぶは今の行だけが対象で、ページをまたいで保たない）。ホバーは行見出しを含む行全体に `--hover-layer` を重ね（割合の色は残して少し沈める。不透明な灰色で塗らない）、選んだ行（`--pri-soft`）は灰色を重ねず `--pri-soft-2` にする。`empty` で行がないときの文、`loading` で読み込み中。`stickyHead` は表の枠を親の高さいっぱいの縦スクロールにして列見出しを上端に残す（親に高さを決めて置く）。`depths`（各行の深さ。0 が最上位、深さ優先の順）は先頭の列を字下げし、読み上げに「第 N 階層」を添える。`stickyHead` と一緒に渡すと、スクロールで見ている行の上位の行を見出しの下に積み、配下が流れ切ったら押し上げて次の上位の行と入れ替える（積んだ行は見出しと同じ地、帯の下端にだけ影。行を複製せず元の行を固定する） |
