## 7. 部品（グラフとキャンバス）

| 部品 | ファイル / CSS | 使いどころ・決まり |
|---|---|---|
| `ChartCard` / `ChartGrid` / `BarList` / `LineChart` | `Chart.tsx` / `chart.css` | グラフの枠（見出し・右端の補足。格子は `ChartGrid`（`.chart-grid`。1 枚 360px 以上で折り返す）、`wide` で格子の横いっぱい）/ 横棒（棒は `--pri`、「なし」「その他」は `muted`。ホバーで名前と数）/ 折れ線（主な系列は `--pri`、補助は `soft`。枠の実際の幅で描く。ホバーで点ごとの期間と値（`unit` を添える）。ホバーした点の印は系列の色で塗りつぶし、地の色の縁を付ける（白抜きの輪にしない。`soft` の点は一段濃い `--chart-3` で小さく）。ホバーの帯はグラフの範囲に収める。点が 1 つだけの系列は線にならないので点を打つ。縦の目盛りは 0 から、`fit` で値のある範囲に合わせる（人数の推移など、0 から描くと変化が見えないもの。棒は 0 から））。系列ごとに色を塗り分けない |
| `Sparkline` / `Funnel` | `Chart.tsx` / `chart.css` | 数字に添える小さな推移の線（目盛りなし。値のない点は飛ばし、点が 1 つなら点）/ 段ごとに減っていく数（段ごとに名前・数・棒と、前の段・最初の段に対する割合。枠が狭ければ 2 列）。`Stat` は `value: null` を「—」にする |
| `StackColumns` / `TileMap` | `Chart.tsx` / `chart.css`（`TileMap` の配置は `squarify.ts`） | 積み上げの縦の棒（期間ごとの内訳を `--chart-1` からの濃淡で下から積み、減った数を 0 の線から下に灰色で。上に合計、`current` の期間を太字）/ 面積と濃さのタイル（面積は `size`、濃さは `ratio`（0〜1、null は値なし）。枠の実際の幅で正方形に近く敷き詰め、押すと選ぶ。小さいタイルは補足 → 名前の順に隠す。`scale` で濃さの凡例） |
| `ColumnChart` / `Waterfall` / `BoxPlot` | `Plot.tsx` / `plot.css` | 縦棒（期間・区分ごとの数。目盛りは 0 から、負の数は 0 の線から下へ。`series` は 3 系列まで `--chart-1` から濃い順に並べ、`histogram` は隙間なく並べる度数の分布、`line` は右の目盛りで重ねる折れ線（件数と率など単位の違う値。棒は `--chart-3` からの薄い段で 2 系列まで）。`current` の項目名を太字。ホバーで項目ごとの値）/ 増減の積み上げ（`start` から増えた分を `--chart-2`、減った分を灰色で積み、棒の上に符号つきの数を書く。`total` で最後に合計の棒）/ 箱ひげ（区分ごとのばらつき。箱は第 1〜第 3 四分位、太い線は中央値、ひげは最小〜最大、点は外れ値。値の並びからは `boxStats`）。目盛りは値を覆う最小の区切り（`axisTicks`） |
| `PieChart` / `Gauge` | `Plot.tsx` / `plot.css` | 全体に対する内訳（`donut` で中央に合計。大きい順に渡し、4 区分までを `--chart-1`〜`4`、残りは `rest`（既定「その他」）の灰色にまとめる。`muted` の区分も灰色。横に名前・数・割合の凡例を必ず並べ、区分へのホバー・凡例へのホバーとフォーカスでその区分を強調し、名前・値・割合の吹き出しを表示）/ 半円のゲージ（目標・上限に対する今の値。`min`〜`max` の弧を値まで `--chart-1`、`target` は目標の目盛り。読み上げは `meter`。`value: null` は「—」。ホバーとフォーカスで名前・値・範囲・目標の吹き出し） |
| `ScatterChart` / `RadarChart` / `HeatMap` | `Plot.tsx` / `plot.css` | 2 つの量の関係（`xLabel`・`yLabel` は必ず書く。目盛りは 0 から、`fit` で値のある範囲。`size` を渡すとバブル（面積が比例）、`muted` は比べる対象の灰色の点。点は半透明で重なりを濃さで見せ、点か点の縁から 32px 以内のホバーで一番近い点を強調して名前と値）/ 項目ごとの数の釣り合い（中心 0・外周 `max`。主な系列は面、`soft` は淡い破線。項目名のホバー・フォーカスと、輪の中のホバーでポインタの向きに一番近い項目を強調して値）/ 行と列の表の濃淡（曜日×時間帯など。濃さは `--chart-5`→`--chart-1`、null は値なしの地、`showValues` でセルに数（地の明るさで黒か白）、`square` は正方形のセルのカレンダーの形、`colEvery` で列の名前を間引く。列が多ければ枠の中だけ横にスクロール。`scale` で濃さの凡例） |
| `Canvas` | `Canvas.tsx`（計算は `canvasGeometry.ts`）/ `canvas.css` | 表示領域より大きな図・ツリーを、ドラッグ・ホイールで動かし、⌘ / Ctrl ＋ホイール・ピンチで拡大縮小する面（20〜160%。＋－は 20〜150% の決まった段階で止める）。動かせるのは中身全体＋80px の余白まで。`start` は最初の位置（`top`: 100% で先頭の節を上部中央、`fit`: 全体が入る倍率）で、動かすまでは表示領域・中身の大きさが変わるたびに置き直す。中身の要素に `data-node`（id）を付けると、右下のミニマップに箱として出し（`data-parent` で線、`data-edge="rail"` で縦に積んだ子の線、`data-on` で強調）、`centerOn`（中央へ運ぶ。遠いほど長く 0.65s まで）・`hold`（開閉の間、画面上の位置を保つ）で位置を合わせられる。操作は `apiRef` か中の部品から `useCanvas`。押した節は詳細パネルが開いてもその場に残し、ドラッグのあとのクリックは中身に届けない。Tab で外の要素へ移ると見える位置まで最小だけ動かす。倍率 40% 未満は名前だけの縮小表示（`.canvas-stage.lod`）。ミニマップは枠が 600px 未満では出さず、拡大縮小のボタン（左下。倍率を押すと 100%）はタッチの端末では出さない |
| `TreeChart` / `TreeCard` / `TreePill` | `Tree.tsx` / `tree.css` | 線でつないだツリー（`Canvas` の中に置く）。根を上に、`columns` の節の子は横の列に、それ以外の子は親の下に縦に積んで左の縦線でつなぐ。縦に積む子は `open`（省略時は内部で持つ）で開閉し、`Collapse` で伸び縮みさせて、開閉した節の画面上の位置を保つ。節は `render` で描く / 節のカード（カード全体が 1 つのボタンで、読み上げの名前は `name`。`label`・`title`・`sub`・`meta`・`more`（閉じているときの補足）。`size`、`level` の枠の強さ（1 が濃く太い。色相は変えない）、`dashed`、`selected`、`dim`。`state` を渡すと開閉のボタン）/ 丸い節（列をまとめる人・区分。`onClick` で押せる）。階層のある一覧（Tree view）とは別で、一覧には `EntityRow` を使う |
